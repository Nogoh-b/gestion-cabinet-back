# Recherche globale

## À quoi ça sert
La recherche globale retrouve en quelques frappes un **dossier, un client, un document, une audience ou une facture** sans passer par les menus. Elle ne montre que ce que votre rôle vous autorise à voir.

## Où le trouver
- **Barre de recherche** en haut de l'écran (« Rechercher dossier, client, document… ») : tapez, puis validez avec Entrée — la page Recherche s'ouvre avec vos résultats.
- **Palette de commandes** : raccourci **Ctrl + K** (⌘ + K sur Mac), champ « Aller à, créer, rechercher… » : permet d'aller à un écran, de lancer une création ou de lancer une recherche (Entrée sur l'option de recherche ; flèches haut/bas pour choisir).
- Page **Recherche** (`/recherche`, adresse `/recherche?q=<texte>`) : champ « Que cherchez-vous ? ».

## Comment ça marche
1. Saisissez votre texte. La recherche part automatiquement après une très courte pause (pas besoin de valider).
2. Les résultats sont regroupés par type avec des onglets : **Tout**, **Dossiers**, **Clients**, **Documents**, **Audiences**, **Factures**, chacun avec son nombre de résultats. Chaque ligne indique le type, un titre et un sous-titre, et mène à la fiche.
3. Les résultats arrivent par pages de 10 ; la suite se charge à la demande.
4. Si rien ne correspond : « Aucun résultat — aucun élément ne correspond à … ». Si la recherche échoue : « La recherche n'a pas pu aboutir. Réessayez. » avec un bouton **Réessayer**.

## Ce qui est cherché
La recherche cherche votre **texte exact** (sans tenir compte des majuscules) *dans* les champs suivants : 
- **Dossiers** : numéro de dossier, objet, description, partie adverse, numéro de dossier au tribunal, nom du tribunal, et nom du client ;
- **Clients** : nom, prénom, raison sociale, code client, e-mail ;
- **Documents** : nom, description, nature du document, et dossier / client liés ;
- **Audiences** : notes, décision, nom du juge, juridiction, type d'audience, dossier / client liés ;
- **Factures** : numéro, libellé, description, et dossier / client liés.
Le texte est cherché comme un tout : « Dupont Jean » ne trouvera que les fiches où ces deux mots apparaissent à la suite ; si vous ne trouvez rien, essayez un seul mot ou une partie du numéro (ex. « 0039 »).

## Règles et droits
- Chaque type n'est cherché que si vous avez la permission de **voir** ce type (dossiers, clients, documents, audiences, factures). Sans la permission, ce type n'apparaît pas.
- Les documents, audiences et factures liés à un **dossier confidentiel** ne s'affichent que si vous avez accès à ce dossier.
- Seules les données de **votre cabinet** sont cherchées.
- Une saisie vide n'affiche rien : « Commencez à taper pour rechercher ».

## Erreurs fréquentes
- Un dossier existe mais n'apparaît pas → il est confidentiel et vous n'y avez pas accès, ou votre rôle ne permet pas de voir les dossiers.
- Aucun résultat avec plusieurs mots → raccourcissez la recherche.

## Depuis le chat
Pour retrouver une information précise (« les factures impayées de Jean Dupont », « les audiences de la semaine »), posez directement la question au chat : il interroge les données de votre cabinet dans la limite de vos droits.
