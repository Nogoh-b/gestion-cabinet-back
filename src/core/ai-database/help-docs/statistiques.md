# Statistiques et rapports avancés

## À quoi ça sert
La page **Rapports avancés** donne une vue d'ensemble de l'activité du cabinet **sur la période de votre choix** : dossiers, audiences, diligences, finances et documents, avec des graphiques, une **comparaison à la période précédente** et un **export**. Chaque liste du logiciel (Clients, Dossiers, Audiences, Documents, Employés, Agences…) affiche en plus ses propres cartes de statistiques en haut de page.

## Où le trouver
- Menu **Statistiques** (`/rapports`, section « Pilotage », permission « voir les rapports »). Le module **Rapports avancés** doit être inclus dans le plan d'abonnement (sinon un écran de mise à niveau s'affiche).
- Les cartes de synthèse propres à chaque module se trouvent en tête des listes (par exemple « Statistiques des dossiers »).

## Utiliser la page — pas à pas
1. Choisissez la **période** avec les deux dates de début et de fin, ou les raccourcis **Ce mois**, **Trimestre**, **Année**.
2. Cochez **Comparer à la période précédente** pour afficher, à côté de chaque indicateur, la variation en % (vert = amélioration, rouge = dégradation ; pour les retards, impayés et durées, une baisse est une bonne nouvelle).
3. Le bouton **Confidentiels exclus / Confidentiels inclus** (visible uniquement avec la permission de voir les dossiers confidentiels) décide si ces dossiers entrent dans les chiffres. Par défaut ils sont exclus.
4. Parcourez les sections ; le lien de chaque section ouvre la liste correspondante (Gérer les dossiers, Voir les audiences, Voir les diligences, Voir les factures, Voir les documents).
5. **Exporter** : bouton **PDF** (rapport mis en page) ou **Excel** (fichier CSV lisible dans Excel, nommé `rapport-<début>_<fin>`).

## Ce que contiennent les sections
- **Évolution mensuelle** : dossiers ouverts / clôturés, chiffre d'affaires facturé / encaissé.
- **Dossiers** : Ouverts, Clôturés, Taux de réussite, Durée moyenne, Urgents (ouverts), Confidentiels (ouverts) ; graphiques Issues (Gagné, Perdu, Transigé, Abandonné, Indéterminé), Par type de procédure, Par avocat référent, Par statut, Par niveau de danger.
- **Audiences** : Total, Tenues, Reportées, Annulées, Taux de report, À venir ; répartition par statut et par juridiction.
- **Diligences** : Total, En cours, Terminées, En retard, Échéances 30 j, Respect des délais ; par statut, priorité et avocat assigné.
- **Finances** : Factures émises, Facturé, Encaissé, Recouvrement, Impayés, Facture moyenne, Dépenses, Marge, Taux de marge, Taux de tenue des audiences ; Balance âgée des impayés et Top clients (facturé).
- **Documents** : Total, Validés, En attente, Refusés, Expirés, Confidentiels, volume de stockage.

## Règles
- Les chiffres ne portent que sur la **période choisie** ; la comparaison utilise la période de même durée qui précède.
- Les dossiers confidentiels sont exclus tant que vous ne les incluez pas et que votre profil n'est pas habilité.
- Une section peut afficher une erreur isolée si ses données ne peuvent être calculées, sans bloquer les autres.
- Les montants s'affichent dans la devise du cabinet (Paramètres du cabinet).

## Erreurs fréquentes
- Menu **Statistiques** absent → permission « voir les rapports » manquante, ou module Rapports avancés non inclus dans le plan (voir Abonnement).
- Chiffres plus faibles que prévu → la période est trop courte, ou des dossiers confidentiels sont exclus.

## Depuis le chat
Pour un chiffre précis, posez la question directement au chat : « combien de dossiers ouverts ce mois ? », « quel est le total des impayés ? ». Il interroge les données dans la limite de vos droits ; la page **Statistiques** reste le meilleur endroit pour les comparaisons, graphiques et exports.
