# Intelligence artificielle

## À quoi ça sert
Choix du moteur IA des cabinets. Les cabinets le consultent seulement.

## Sections
- **Moteur par défaut des cabinets** : utilisé par tous les cabinets, sauf exception.
- **Fournisseurs** : les fournisseurs intégrés utilisent les clés du serveur ; on peut ajouter des API compatibles OpenAI (**Modèle**, **Base URL (HTTPS)**, **Clé API**). La clé est chiffrée et n'est plus jamais affichée.
- **Base de connaissance juridique** : import de PDF de référence (10 Mo maximum), cités par le chat.
- **Exceptions par cabinet** : pour en ajouter une, ouvrir la fiche du cabinet.

Les réglages sont réservés au rôle **Propriétaire**.
