# Sauvegardes

## À quoi ça sert
Exports SQL complets de la base, tous cabinets confondus. Page réservée au rôle **Propriétaire**.

## Actions
**Télécharger**, **Restaurer**, **Supprimer**.

## Restaurer
La restauration **écrase toutes les données**. La fenêtre **Restaurer la base complète** demande de taper **RESTAURER** pour confirmer. L'assistant ne propose jamais cette action.
