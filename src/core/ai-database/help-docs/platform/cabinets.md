# Cabinets

## À quoi ça sert
Tous les cabinets inscrits, leur abonnement et leur chiffre d'affaires. Filtres : **Recherche** (nom, code ou email), **Statut du cabinet**, **Abonnement**, **Plan**.

## La fiche d'un cabinet
Onglets : **Aperçu**, **Historique**, **Paiements**, **Utilisateurs**, **Dossiers**, **Données de test**, **Journal**.

Les boutons en haut de la fiche dépendent du rôle : **Suspendre** / **Réactiver**, **Prolonger**, **Offrir des mois**, **Offrir l'illimité**, **Changer de plan**, **Résilier**, **Enregistrer un paiement**, **Code promo**, **Se connecter en tant que**, **Écrire au cabinet**.

## Suspendre un cabinet
1. Ouvrir la fiche du cabinet, cliquer sur **Suspendre**.
2. Saisir le **Motif** (obligatoire).
3. Confirmer : les utilisateurs perdent l'accès immédiatement.

Une suspension manuelle n'est jamais levée automatiquement, ni par un paiement ni par une prolongation. Rôles : Propriétaire, Finance, Support.

## Réactiver un cabinet
1. Sur la fiche, cliquer sur **Réactiver** (visible si la suspension est manuelle).
2. Confirmer. La suspension manuelle est levée ; si l'abonnement est échu ou en attente de paiement, le cabinet reste bloqué pour ce motif.

## Se connecter en tant que
Rôles Propriétaire et Support. Choisir l'utilisateur, saisir le motif : l'espace du cabinet s'ouvre dans un nouvel onglet pendant 1 heure. Toutes les actions sont tracées ; paiements, mots de passe et rôles restent bloqués.

## Utilisateurs d'un cabinet
Onglet **Utilisateurs** (Propriétaire, Support) : bloquer ou débloquer, envoyer un code de réinitialisation du mot de passe, désactiver la double authentification.

## Écrire au cabinet
Le message part vers l'email de contact et les administrateurs actifs du cabinet.
