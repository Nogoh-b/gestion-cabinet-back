# Codes promo

## À quoi ça sert
Remises proposées aux cabinets à l'inscription, au changement de plan ou sur une échéance due.

## Créer un code
Champs : **Code**, **Description (interne)**, **Type**, **Cycle éligible**, **Échéances remisées**, **Utilisations max (total)** (vide = illimité), **Utilisations max par cabinet**, **Valable à partir du**, **Valable jusqu'au**, **Plans éligibles** (aucun coché = tous).

## Appliquer un code à un cabinet
Sur la fiche du cabinet, quand une échéance est due, bouton **Code promo** (rôles Propriétaire, Finance, Support). La remise s'applique à l'échéance due, avant paiement.

## Suivre
Le bouton **Utilisations** d'un code liste ses usages.
