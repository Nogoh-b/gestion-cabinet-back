# Documentation de la console plateforme

Fiches de l'assistant de la console `/platform`, une par page. Même format que
`../README.md` (en-tête `id`, `title`, `keywords`, `paths`), chargées avec
`loadHelpDocs('platform')`. Ce dossier n'est jamais servi aux cabinets : la lecture
de `help-docs/` n'est pas récursive.
