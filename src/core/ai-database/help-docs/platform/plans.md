# Plans

## À quoi ça sert
Offre commerciale : tarifs, essai, quotas et modules. Un plan désactivé n'est plus proposé aux nouveaux cabinets.

## Créer ou modifier un plan
Champs : **Code**, **Description**, **Prix mensuel (XAF)**, **Prix annuel (XAF)**, **Jours d'essai**, **Engagement (mois)**, **Niveau de support**.
- **Quotas** : -1 signifie illimité.
- **Modules** : cocher ceux qui sont inclus. Pour l'IA, le champ fixe les crédits du forfait (vide ou -1 = illimité).

## Règles
- Pas d'essai sur un plan gratuit.
- L'essai et la période payante s'enchaînent : fin d'essai, puis un cycle complet.
- Un quota illimité sur un plan n'a rien à voir avec un **abonnement illimité** : celui-ci porte sur la durée. Voir la fiche Abonnements.
