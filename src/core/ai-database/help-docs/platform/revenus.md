# Revenus

## À quoi ça sert
Audit mensuel : **encaissé** (à la date de paiement), remboursements, frais et **revenu reconnu** (étalé sur la période couverte, hors essai).

## Accès
Rôles **Propriétaire** et **Finance** uniquement.

## Lire la page
1. Choisir l'**Année**.
2. Lire les indicateurs : encaissé, **Net (après remboursements et frais)**, **Revenu reconnu**, **Cabinets**.
3. Le tableau **Détail mensuel** donne le mois par mois.

## Règles
- Le MRR compte les abonnements actifs, hors essai, de montant positif, et exclut les cabinets en suspension manuelle. Un abonnement illimité offert a un montant nul : il n'entre pas dans le MRR.
