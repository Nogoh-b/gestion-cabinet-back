# Administrateurs

## À quoi ça sert
Comptes ayant accès à la console. La connexion exige toujours un code envoyé par email. Page réservée au rôle **Propriétaire**.

## Inviter un administrateur
1. Cliquer sur **Inviter un administrateur**.
2. Saisir **Nom complet**, **Email**, **Rôle**.
3. **Envoyer l'invitation** : un email permet de définir le mot de passe (lien valable 72 h).

## Rôles
- **Propriétaire** : tous les droits.
- **Finance** : revenus, paiements, résiliation, illimité, crédits IA, actions d'abonnement.
- **Support** : actions d'abonnement courantes, utilisateurs des cabinets, connexion en tant que, référentiels.

Le changement de rôle ferme les sessions en cours de la personne.
