# Référentiels

## À quoi ça sert
Configuration de départ des cabinets, organisée en profils. Rôles **Propriétaire** et **Support**.

## Sections
**Rôles**, **Catalogue des permissions**, **Attributions aux rôles**, **Catalogue d'actions**, **Devises**, **Référentiels métier**, **Procédures**, **Modèles**, **Configuration initiale**, **Configuration globale**, **Versions**, **Applications aux cabinets**.

## Cycle de travail
1. Modifier une section : les changements vont dans un brouillon.
2. **Configuration globale** : vérifier les dépendances et publier le profil.
3. **Applications aux cabinets** : comparer les différences, choisir les cabinets, suivre les applications.

**Versions** consulte les publications et prépare une révision depuis une ancienne version.

## Assistant des référentiels
Les pages de référentiels ont leur propre assistant, spécialisé dans le contenu du profil, qui prépare des propositions pour le brouillon.
