# Profil et préférences

## À quoi ça sert
Votre **profil** réunit vos informations personnelles, vos **demandes** (avances sur salaire, permissions/congés) et la **sécurité** de votre compte (mot de passe, double authentification). Les **préférences** règlent la langue, le thème et l'apparence de votre interface.

## Où le trouver
- Menu du compte (avatar) > **Mon profil** : ouvre `/settings/profile` (administrateur : informations du compte — nom complet, e-mail, rôle, téléphone) ou **`/profil`** en self-service pour les collaborateurs (avocat, secrétaire, stagiaire…) : c'est leur espace personnel.
- Page **`/profil`** (self-service) : trois onglets — **Aperçu** (coordonnées, statistiques : dossiers, audiences…), **Mes demandes** (ouvert par défaut pour les collaborateurs), **Sécurité**.
- Menu du compte > **Préférences** (`/settings/user`) : langue, thème (clair / sombre / système), polices, taille, style de la barre latérale, téléphone, signature, avatar, changement de mot de passe. Chaque réglage est enregistré aussitôt (« Préférence mise à jour »).

## Mes demandes (collaborateurs) — pas à pas
1. Ouvrez **Mon profil** (`/profil`) > onglet **Mes demandes**.
2. **Nouvelle demande** : **avance sur salaire** (montant, motif ; le montant ne peut pas dépasser votre salaire) ou **permission / congé** (dates, motif).
3. Suivez l'état : Demandée → Approuvée / Refusée (motif obligatoire) / Annulée ; une avance approuvée est ensuite **versée**, puis **récupérée** sur vos bulletins de paie.
4. Vous êtes **notifié** de chaque décision. L'administrateur traite vos demandes depuis votre fiche employé (il peut ajuster dates ou montant avant de valider).

## Sécurité du compte
- Onglet **Sécurité** de `/profil` (ou Administration > Authentification) : **activer / désactiver la double authentification** (OTP par e-mail — un code est alors demandé à chaque connexion en plus du mot de passe) et **réinitialisation du mot de passe** (e-mail de réinitialisation envoyé à votre adresse).
- À la première connexion, le mot de passe temporaire reçu par e-mail doit être changé.
- Préférences > changement de mot de passe : mot de passe actuel + nouveau (indication de robustesse affichée).

## Règles
- Votre e-mail est votre **identifiant de connexion** ; il ne se change pas seul — voyez l'administrateur.
- Votre **rôle** (profil d'accès) est choisi par l'administrateur dans votre fiche employé ; il décide de vos menus et boutons.
- L'apparence du cabinet (logo, couleurs par défaut) se règle dans menu du compte > **Cabinet** (administrateur) ; vos préférences personnelles priment pour votre affichage.

## Erreurs fréquentes
- « Mes demandes » vide → vous n'avez encore rien demandé, ou vos demandes sont archivées.
- « L'avance ne peut pas dépasser le salaire » → réduisez le montant.
- Code de double authentification non reçu → vérifiez vos spams et l'adresse du compte ; la configuration SMTP du cabinet peut être en cause (administrateur).
- Page Mon profil différente de celle d'un collègue → normal : administrateur et collaborateur n'ont pas la même page.

## Depuis le chat
Le profil et les préférences se règlent dans ces pages, pas depuis le chat. Je peux en revanche créer votre demande (« Demande une avance de 50 000 FCFA, motif frais de transport ») avec carte de confirmation avant enregistrement.
