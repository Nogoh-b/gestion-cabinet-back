# Compétences « Documents »

## La carte Document (commune)
Les compétences qui produisent un document affichent une carte : **Nom du document** et les champs à relire (destinataire, objet, corps…), puis :
- **Aperçu** : le PDF s'ouvre dans un nouvel onglet ;
- **Télécharger** : le PDF est enregistré sur votre poste ;
- **Classer dans le dossier** (si un dossier est visé) : le PDF est ajouté à la GED du dossier ;
- après classement, **Envoyer par e-mail** lance la compétence Envoyer un e-mail avec ce PDF en pièce jointe.
Le PDF reprend l'en-tête et le pied de page du cabinet. Les courriers utilisent les **modèles PDF** du cabinet (Plus › Configuration › Modèles) ; les autres documents (conclusions, notes, décomptes…) ont une mise en page intégrée, remplacée par un modèle du cabinet de même code s'il en crée un.

## Courrier
- Mentionnez si possible un dossier, un client, une audience ou une facture (facultatif). L'IA rédige destinataire, adresse, objet et corps ; le modèle **Général — Courrier type** ajoute en-tête, date, formule de politesse et signature (vous, avec votre fonction et le cabinet).
- Champs : Destinataire, Adresse du destinataire, Objet, Corps du courrier, Signataire, Qualité du signataire.

## Mise en demeure
- Même fonctionnement avec le modèle **Général — Mise en demeure** (mention « Lettre recommandée avec accusé de réception » et clause de régularisation sous huitaine déjà imprimées).
- Destinataire par défaut : la **partie adverse** du dossier (le débiteur). L'IA rappelle les faits, l'obligation, les montants fournis et le délai.

## Document depuis un modèle
- Mentionnez la fiche (dossier, client, audience, diligence ou facture) et nommez le document : « attestation de suivi », « avis d'audience au client », « synthèse », « ordre de mission »… La compétence choisit le modèle PDF actif du cabinet dont le nom correspond ; sinon elle liste les modèles disponibles.
- Le document est rempli avec les données de la fiche (comme l'export PDF de la page) : rien à rédiger.

## Traduire (français ↔ anglais)
- Source : le passage cité, la pièce jointe (ou **@** document), le texte collé après « : », sinon la dernière réponse du chat. Langue d'arrivée : celle demandée (« en anglais », « into French »), sinon l'autre langue.
- Traduction juridique fidèle (terminologie OHADA, Cameroun bilingue), sans résumé. Étape suivante : **En faire un courrier PDF**.

## Version bilingue FR | EN
- Même source que la traduction. Le texte est découpé en paragraphes ; chaque paragraphe est placé à côté de sa traduction dans un **PDF en deux colonnes** (format paysage) : Français | English.
- Utile pour les juridictions anglophones, les clients étrangers et les contrats bilingues. Un paragraphe non traduit est signalé « (traduction manquante) ».

## Anonymiser un document
- Source : pièce jointe, document mentionné, passage cité, texte collé ou dernière réponse.
- L'IA repère les noms, raisons sociales, adresses, téléphones, e-mails, numéros (CNI, comptes, immatriculations) et lieux ; les e-mails, téléphones et longs numéros sont aussi repérés automatiquement. Chaque donnée reçoit un **pseudonyme cohérent** partout dans le texte : Personne A, Société B, [adresse 1], [téléphone 1]… (« M. Dupont » devient aussi « Personne A »).
- La réponse affiche le texte anonymisé et la **table de correspondance** (confidentielle : elle n'est pas dans le PDF). La carte permet de corriger le texte avant de générer le PDF « Document anonymisé ».
- Relisez toujours : une donnée inhabituelle peut échapper au repérage.
