# Abonnement et plan

## À quoi ça sert
L'abonnement définit ce que le cabinet peut utiliser dans KabySoft : **limites** (collaborateurs, clients, dossiers, agences, audiences, stockage…), **modules inclus** (Paie, Dépenses, Documents, Facturation, Rapports avancés, Assistant IA) et **durée** (période d'essai, échéance, renouvellement). Il se consulte et se change soi-même, sans passer par le support.

## Où le trouver
- Menu du compte (avatar) > **Abonnement** (`/abonnement`, administrateur uniquement) : page « Mon abonnement ».
- Bouton **Changer de plan** (`/abonnement/changer`) en haut de la page.
- Les quotas en cours d'utilisation s'affichent aussi dans la page, bloc « Utilisation en temps réel ».

## Ce que montre la page « Mon abonnement »
- **Plan actif** : nom, description, prix mensuel et annuel ; un compteur de jours restants si c'est une période d'essai.
- **Échéance et cycle de facturation** : « Prochaine échéance » (ou « Période d'essai »), jours restants ou « Échéance dépassée — accès suspendu », bascule **Mensuel / Annuel**.
- **Limites du plan** : Collaborateurs, Clients, Dossiers, Agences, Audiences, Stockage, Support, Engagement. « Illimité » ou ∞ = pas de limite.
- **Modules inclus** : Paie, Dépenses, Documents, Facturation, Rapports avancés, Assistant IA — chacun marqué **Inclus** ou **Non inclus**.
- **Historique de facturation** : échéance, période, montant, statut (En attente, En vérification, Payé, Échoué, Remboursé) et **Reçu** téléchargeable.

## Changer de plan — pas à pas
1. **Abonnement > Changer de plan**.
2. Choisissez le cycle **Mensuel** ou **Annuel** (l'annuel affiche une réduction).
3. Cliquez le plan voulu (carte avec prix, nombre de collaborateurs, dossiers, stockage, clients, badge **IA** si l'assistant est inclus, **Plan actuel** sur le vôtre).
4. Confirmez : « Plan mis à jour ». Un changement de plan ouvre une **nouvelle période** ; un simple changement de cycle met à jour l'abonnement en place.
5. Si le plan est payant, un bandeau **Paiement requis** apparaît : l'abonnement est activé à la confirmation du paiement.

## Payer
Dans le bandeau « Paiement requis » :
1. (Facultatif) saisissez un **code promo** (« Code promo appliqué »).
2. Choisissez un **moyen de paiement**. Les paiements en ligne s'ouvrent sur la page du prestataire ; les paiements **manuels** (virement, mobile money) portent la mention « validation manuelle ».
3. Pour un paiement manuel : effectuez le virement avec la **Référence à indiquer**, puis déclarez-le (« Une fois le paiement effectué, déclarez-le ») en saisissant la **Référence / ID de transaction** (obligatoire), un commentaire facultatif et, si demandé, une preuve. Message : « Paiement déclaré — en cours de vérification » ; l'équipe de la plateforme le valide ensuite.

## Règles
- **Période d'essai** : seuls certains plans payants en offrent une (durée propre au plan, parfois avec un engagement de quelques mois) ; les plans gratuits n'en ont pas. Au terme de l'essai, la période payante démarre.
- **Échéance dépassée** : l'abonnement est **suspendu** et l'accès au cabinet est bloqué jusqu'au paiement. Le bouton **Renouveler maintenant** apparaît ; il reste utilisable même quand le cabinet est suspendu.
- **Quotas** : quand une limite est atteinte, la création est refusée jusqu'à la mise à niveau du plan. Un volume « illimité » est marqué par ∞ ou « Illimité ».
- **Modules** : un module non inclus (Paie, Dépenses, Documents, Facturation, Rapports, IA) est inaccessible et masqué des menus.
- Seul l'administrateur voit l'abonnement.

## Erreurs fréquentes
- « Limite de … atteinte (x/y). Veuillez mettre à niveau votre plan … » → ouvrez **Changer de plan**.
- « Le module … n'est pas inclus dans votre plan » → choisissez un plan qui l'inclut.
- « Espace de stockage insuffisant (… Go / … Go utilisés) » → libérez de l'espace ou changez de plan.
- « Échéance dépassée — accès suspendu » → renouvelez et réglez l'échéance.
- « Indiquez la référence de votre paiement » → la référence est obligatoire pour une déclaration manuelle.
- « Un code promo est déjà appliqué à cette échéance » / « Aucune échéance à régler ».
- « Aucun moyen de paiement n'est disponible pour le moment » → contactez le support.

## Créer depuis le chat
L'abonnement ne se modifie pas depuis le chat : utilisez la page **Abonnement**. Je peux en revanche vous dire à quoi sert chaque limite ou module, et vous guider vers **Changer de plan** quand un message d'erreur évoque un quota.
